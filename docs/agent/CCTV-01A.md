# [Claude → Codex] CCTV-01A UE 없이 진행하는 작업

[CCTV-01](CCTV-01.md) 진행 중 사용자가 UE 사용 중단을 요청했다. 이 PC의 UE와 GPU는 다른 작업이 사용 중이다. 사용자가 별도로 요청하기 전까지 아래 금지를 지킨다. CCTV-01의 4~8번은 보류한다.

## 절대 금지

- 실행 금지: `UnrealEditor*`, `UnrealBuildTool`, `Build.bat`, `RunUAT`, `ShaderCompileWorker`, 패키지 실행 파일, Docker, `mediamtx`, `ffmpeg`, 그 밖에 GPU를 쓰거나 CPU를 오래 점유하는 작업
- 프로세스 종료 금지: 어떤 프로세스도 종료하지 않는다. 다른 작업의 프로세스가 보여도 건드리지 않는다.
- `C:\Unreal Projects\UE-DT-CCTV-Plugin` 밖의 파일 수정 금지
- `git add -A`, push, PR, merge 금지

금지 때문에 끝낼 수 없는 일은 "UE 필요, 미수행"으로 기록하고 넘어간다.

## 기준

- branch: `feature/cctv-plugin-v1`, 작업 트리에 이어서 작업한다.
- 3번까지의 결과는 `Saved/Reports/CCTV-01/progress.json`에 반영한다. 패키지는 `C:\Users\ho270\AppData\Local\Temp\cctv\pkg`에 있으며 지우지 않는다.
- `TestHost/Config/DefaultEngine.ini`의 미커밋 변경은 내용을 확인해 정리한다. 토큰은 출력하지 않고, 값이 있으면 지운다.

## 할 일 (순서대로)

1. **코드 재검토(CCTV-01의 9번):** 스레드 경합, 수명, 종료 순서, 오류 경로를 읽어서 점검한다. 특히 렌더 명령 대기 중 `UDTCctvStream` 파괴, `FDTCctvSession` 종료, 해상도 변경, `ActiveHwSessions` 집계, 업로드 전 축소 경로를 본다. 확인된 결함은 작은 커밋으로 고치고, 불확실한 것은 고치지 말고 기록한다.
2. **시험 스크립트 안전화:** `TestHost/Scripts/fault_test.ps1`이 프로세스를 이름으로 종료하지 않게 고친다. 스크립트가 직접 시작한 프로세스만 PID로 종료한다. 시작 전에 다른 언리얼 프로세스가 있으면 측정을 시작하지 않고 알린다.
3. **보류된 시험 준비:** 실행은 하지 않고 코드와 스크립트만 작성한다.
   - 하네스에 크기 변경과 `SubUrl` 전환 시나리오 옵션을 추가한다. 시나리오는 아래 표를 모두 다룬다.
   - 4~8번을 한 번에 하나씩 실행하고 결과를 `Saved/Reports/CCTV-01/`에 남기는 `TestHost/Scripts/run_pending_gates.ps1`을 작성한다.
4. **문서(CCTV-01의 10번):** `README.md`를 쓰고 `docs/DESIGN.md`를 현재 구현에 맞춘다. 재연결 상태 표시가 운영 위젯의 책임임을 적는다. 측정값은 실제로 측정된 것만 조건과 함께 쓴다. 미측정 항목을 달성했다고 쓰지 않는다.
5. **결과 작성:** `Saved/Reports/CCTV-01A/RESULT.md`와 `result.json`을 쓴다.

## 검증 한계

이번 변경은 컴파일하지 못한다. C++와 C# 변경은 커밋 메시지와 결과에 "빌드 미검증"으로 표시한다. 문법과 include를 눈으로 다시 확인하고, 공개 API의 이름 변경과 삭제는 하지 않는다.
